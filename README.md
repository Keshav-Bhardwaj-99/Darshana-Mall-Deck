# Darshana | Interactive Sales Experience

> A world-class, browser-based, cinematic pitch deck for the American Dream mall. Built to replace traditional static presentations with a data-driven, video-first interactive experience.

## 🚀 Live Demo
**[darshana-mall-deck.vercel.app](https://darshana-mall-deck.vercel.app/)**

---

## ✨ Core Features

### 🎬 Cinematic Storytelling
- **Video-First UX:** Background hero videos and hover-triggered cinematic loops for all event venues.
- **Preloader:** A high-end brand reveal animation to set the tone and manage asset loading.
- **Ambient Audio:** Optional luxury lounge ambience with a minimalistic mute/unmute control.

### 🗺️ Advanced Interactivity
- **Interactive Map Navigator:** A fixed-position luxury map allowed prospected tenants to jump between zones (Retail, Entertainment, Events) instantly.
- **3D Tilt Components:** Venue and attraction cards respond to mouse movement with sophisticated 3D parallax effects.
- **Experience Lightboxes:** Detailed attraction insights with high-resolution AI visuals and key performance stats.

### 📊 Tenant Intelligence
- **Data Dashboard:** Integrated analytics section showing simulated footfall trends and shopper demographics using animated charts.

## 🛠️ Technical Stack
- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4 (Modern luxury color palette: #D4AF37, #F5F5F7, #0A0A0A)
- **Animation:** Framer Motion (Spring-based physics and viewport-triggered reveals)
- **Icons:** Lucide React, React Icons & Font Awesome
- **Performance:** Optimized Lighthouse score (100 Accessibility) with lazy loading and resource pre-fetching.

## 📦 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Keshav-Bhardwaj-99/Darshana-Mall-Deck.git
   ```
2. Install dependencies:
   ```bash
   cd mall-deck
   npm install
   ```
3. Run Development Server:
   ```bash
   npm run dev
   ```
4. Build for Production:
   ```bash
   npm run build
   ```
